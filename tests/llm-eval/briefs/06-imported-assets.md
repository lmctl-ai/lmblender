# 06 Imported assets
In `assets/` you have `study.obj` (with its own `study.mtl` and texture images), `gallery.glb` (a textured glTF
scene) and `checker-texture.png`. Import the OBJ with its own materials and the glTF, add a cube that uses
`checker-texture.png` as its image texture, place all three side by side on a floor, light them, and frame
the view so everything is fully visible. Output: `out/imports.png`, 960x540.
