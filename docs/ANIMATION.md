# Animation and frame output

`Mesh.keyframe_transform(frame, x, y, z, interpolation)` keys the mesh object's absolute scene-space translation in renderer units (Z up). `Mesh.translate(dx,dy,dz)` is additive while authoring the initial scene; key values replace that resulting translation while sampling animation. The current mesh model has no parent transform, so keyed coordinates are independent of call order after keys are set. Interpolation is `linear` or smoothstep `ease`; repeated keys at one frame replace the previous key.

`Mesh.keyframe_visible(frame, visible, interpolation)` holds the visibility state between keys and omits the mesh from Cycles scene construction when false. `Material.keyframe_color(frame,r,g,b,interpolation)` keys base color channels in [0,1], while `Material.keyframe_emission_strength(frame,strength,interpolation)` keys emission strength in [0,1000000]. `Scene.camera_keyframe(frame,px,py,pz,tx,ty,tz,interpolation)` keys camera position and target in scene coordinates. `Scene.camera_optics_keyframe(frame,vertical_fov_degrees,orthographic_vertical_span,interpolation)` keys perspective vertical FOV and orthographic vertical span; the current projection mode still comes from the camera setup call. `Scene.point_light_keyframe(light_index,frame,strength,interpolation)` animates a point light by its zero-based creation index.

`Scene.render_sequence(pattern, first, last, samples, width, height)` renders inclusive integer frames. The path pattern must contain `{frame}` or `####`; the latter is zero-padded to four digits. `Scene.render_apng(path, first, last, samples, width, height, fps)` renders the same animation into an atomically published APNG. APNG frame delay is stored as the exact rational `1/fps`. Both APIs enforce a 240-frame / 64-million total-pixel budget and use the configured deterministic render seed.

The sequence and APNG APIs interpolate mesh translation/visibility, camera position/target/optics, material color/emission strength, and point-light strength. They restore the authored scene state after rendering. `Scene.motion_blur(enabled, shutter_frames)` samples keyed mesh translation/visibility, camera position/target/optics, material color/emission and point-light strength; shutter duration is limited to 0.1–2 frames. On aarch64/GCC 14, GDB showed Cycles' per-ray motion interpolation occasionally receiving a time value far outside [0,1], even after disabling tree vectorization and compiling the CPU kernel at -O1. The host therefore renders nine static shutter-time samples and averages them; it does not enter the unstable per-ray interpolation path. This creates a slight multi-sample/ghosted look at fast motion rather than exact continuous per-ray blur. Mesh rotation/scale and material roughness/metallic are not keyed yet. `tests/motion_blur_quality.py` measures the animated sphere's red-mask width against the sharp control. `tests/animation_visibility_quality.py` asserts visibility disappears at the keyed frame, emission brightness rises, and the camera's wider FOV reduces projected object size.
