# gltf-import in lmblender and Blender

Goal: render [examples/gltf-import.lms](../../../examples/gltf-import.lms) with lmblender and the same scene with Blender 5.2 from Python, and compare the results.

Left: lmblender. Right: Blender.

![import-gltf-gltf.png: lmblender left, Blender right](images/gltf-import--import-gltf-gltf.jpg)

`import-gltf-gltf.png`: mean absolute difference 19.4 of 255, silhouette overlap 1.00.

## Timing

| Renderer | Seconds, whole run | Binary |
|---|---|---|
| lmblender | 1.7 | v0.3.4 release |
| Blender 5.2.2 | 2.0 | source build, Cycles CPU, about 0.8 s of it is Blender startup |

Both runs used four threads on a four-core Neoverse-N1 (AWS Graviton2) Linux arm64 host.

## Differences and gaps

- Blender's glTF importer splits vertices differently, so the vertex count check reports 8 where lmblender reports 4. The base-color PNG renders lighter in lmblender because it is read without sRGB decoding.
- Blender `expect_int` checks: expect_int MISMATCH: actual=4 expected=2; expect_int MISMATCH: actual=8 expected=4.
- lmblender's Standard view transform renders dark tones darker than Blender (for example 38 instead of 56 out of 255 for a linear value of 0.04), which accounts for most of the difference on dark backgrounds.

## Run both

From the repository root (the Blender command needs Blender 5.x on your PATH):

```sh
mkdir -p build
lmscript examples/gltf-import.lms
blender -b --factory-startup --python docs/tutorial/blender/py/gltf-import.py
```

lmblender writes into `build/`; the Blender port writes the same file names into `blender/`. The lmblender example prints nothing when it succeeds, so check that the image exists; it also leaves its compiled `.dslb` file in `build/`.

## Blender port

The port calls [lmb_bpy.py](py/lmb_bpy.py), which implements each lmblender call with bpy and the host's semantics.

<!-- code: blender/py/gltf-import.py -->
```python
# SPDX-FileCopyrightText: 2025-2026 lmblender contributors
# SPDX-License-Identifier: MIT
# Blender/bpy port of examples/gltf-import.lms (generated by docs/tutorial/blender/lms2py.py, reviewed by hand)
import os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import lmb_bpy

scene = lmb_bpy.Scene()
first = scene.import_gltf("tests/fixtures/gltf/gallery.gltf")
scene.expect_int(first.vertex_count(), 4)
scene.expect_int(first.triangle_count(), 2)
scene.world_color(0.22, 0.25, 0.3, 0.12)
scene.area_light(0.0, -4.5, 4.5, 0.0, 0.0, 1.0, 1.0, 0.95, 0.85, 180.0, 4.0)
scene.camera_look_at(0.0, -9.0, 2.8, 0.0, 0.0, 1.0, 42.0)
scene.render_settings(8, 31, False)
scene.render_png("blender/import-gltf-gltf.png", 20, 640, 480)
lmb_bpy.done()
```
