# render-settings in lmblender and Blender

Goal: render [examples/render-settings.lms](../../../examples/render-settings.lms) with lmblender and the same scene with Blender 5.2 from Python, and compare the results.

Left: lmblender. Right: Blender.

![render-settings.png: lmblender left, Blender right](images/render-settings--render-settings.jpg)

`render-settings.png`: mean absolute difference 0.3 of 255, silhouette overlap 0.99.

## Timing

| Renderer | Seconds, whole run | Binary |
|---|---|---|
| lmblender | 0.6 | built from source with the fixes on page 11 (v0.3.4 plus the color, camera, and denoiser fixes) |
| Blender 5.2.2 | 1.5 | source build, Cycles CPU, about 0.8 s of it is Blender startup |

Both runs used four threads on a four-core Neoverse-N1 (AWS Graviton2) Linux arm64 host.

## Differences and gaps

- The scene sets no camera. In v0.3.4 lmblender's fallback view was squeezed about 1.5 times horizontally at 4:3; the fixed build and the port both use an undistorted view.

## Run both

From the repository root, with lmscript and Blender 5.x on your PATH:

```sh
mkdir -p build
lmscript examples/render-settings.lms
blender -b --factory-startup --python docs/tutorial/blender/py/render-settings.py
```

Expected lmblender output (the host's JSON result):

```text
{"ok": true, "result": null}
```

Expected Blender output, among Blender's own log lines (seconds vary from run to run):

```text
blender render blender/render-settings.png: 0.36s
blender total 0.42s
```

lmblender writes into `build/`, including the compiled `.dslb`; the Blender port writes the same file names into `blender/`. Ubuntu's packaged Blender 4.0 also runs the ports, but without denoising (it has no OpenImageDenoise) and its glTF importer needs `python3-numpy`.

## Blender port

The port calls [lmb_bpy.py](py/lmb_bpy.py), which implements each lmblender call with bpy and the host's semantics.

<!-- code: blender/py/render-settings.py -->
```python
# SPDX-FileCopyrightText: 2025-2026 lmblender contributors
# SPDX-License-Identifier: MIT
# Blender/bpy port of examples/render-settings.lms (generated by docs/tutorial/blender/lms2py.py, reviewed by hand)
import os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import lmb_bpy

scene = lmb_bpy.Scene()
mesh = scene.import_obj("tests/fixtures/tetra.obj")
scene.render_settings(8, 1234, False)
scene.render_png("blender/render-settings.png", 24, 192, 144)
lmb_bpy.done()
```
