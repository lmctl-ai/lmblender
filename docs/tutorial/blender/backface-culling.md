# backface-culling in lmblender and Blender

Goal: render [examples/backface-culling.lms](../../../examples/backface-culling.lms) with lmblender and the same scene with Blender 5.2 from Python, and compare the results.

Left: lmblender. Right: Blender.

![backface-culling.png: lmblender left, Blender right](images/backface-culling--backface-culling.jpg)

`backface-culling.png`: mean absolute difference 0.3 of 255, silhouette overlap 1.00.

## Timing

| Renderer | Seconds, whole run | Binary |
|---|---|---|
| lmblender | 1.3 | built from source with the fixes on page 11 (v0.3.4 plus the color, camera, and denoiser fixes) |
| Blender 5.2.2 | 2.0 | source build, Cycles CPU, about 0.8 s of it is Blender startup |

Both runs used four threads on a four-core Neoverse-N1 (AWS Graviton2) Linux arm64 host.

## Differences and gaps

- No known differences beyond sampling noise.

## Run both

From the repository root, with lmscript and Blender 5.x on your PATH:

```sh
mkdir -p build
lmscript examples/backface-culling.lms
blender -b --factory-startup --python docs/tutorial/blender/py/backface-culling.py
```

Expected lmblender output (the host's JSON result):

```text
{"ok": true, "result": null}
```

Expected Blender output, among Blender's own log lines (seconds vary from run to run):

```text
blender render blender/backface-culling.png: 1.00s
blender total 1.07s
```

lmblender writes into `build/`, including the compiled `.dslb`; the Blender port writes the same file names into `blender/`. Ubuntu's packaged Blender 4.0 also runs the ports, but without denoising (it has no OpenImageDenoise) and its glTF importer needs `python3-numpy`.

## Blender port

The port calls [lmb_bpy.py](py/lmb_bpy.py), which implements each lmblender call with bpy and the host's semantics.

<!-- code: blender/py/backface-culling.py -->
```python
# SPDX-FileCopyrightText: 2025-2026 lmblender contributors
# SPDX-License-Identifier: MIT
# Blender/bpy port of examples/backface-culling.lms (generated by docs/tutorial/blender/lms2py.py, reviewed by hand)
import os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import lmb_bpy

scene = lmb_bpy.Scene()
visible = scene.plane(1.65)
visible.rotate_x(-90.0)
visible.translate(-1.05, 0.0, 0.0)
green = scene.material(0.02, 0.9, 0.08, 0.0, 0.5, 0.0, 0.02, 0.9, 0.08, 1.0)
visible.set_material(green)
hidden = scene.plane(1.65)
hidden.rotate_x(-90.0)
hidden.translate(1.05, 0.0, 0.0)
red = scene.material(0.9, 0.02, 0.02, 0.0, 0.5, 0.0, 0.9, 0.02, 0.02, 1.0)
red.backface_culling(True)
hidden.set_material(red)
scene.world_color(0.25, 0.27, 0.3, 0.35)
scene.camera_look_at(0.0, -6.0, 0.0, 0.0, 0.0, 0.0, 40.0)
scene.render_png("blender/backface-culling.png", 16, 640, 480)
lmb_bpy.done()
```
