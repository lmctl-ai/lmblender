# render-mesh-xml-oracle in lmblender and Blender

Goal: render [examples/render-mesh-xml-oracle.lms](../../../examples/render-mesh-xml-oracle.lms) with lmblender and the same scene with Blender 5.2 from Python, and compare the results.

Left: lmblender. Right: Blender.

![imported-mesh-xml.png: lmblender left, Blender right](images/render-mesh-xml-oracle--imported-mesh-xml.jpg)

`imported-mesh-xml.png`: mean absolute difference 4.9 of 255, silhouette overlap 0.99.

## Timing

| Renderer | Seconds, whole run | Binary |
|---|---|---|
| lmblender | 1.0 | v0.3.4 release |
| Blender 5.2.2 | 1.2 | source build, Cycles CPU, about 0.8 s of it is Blender startup |

Both runs used four threads on a four-core Neoverse-N1 (AWS Graviton2) Linux arm64 host.

## Differences and gaps

- The scene sets no camera. lmblender's fallback view is squeezed about 1.5 times horizontally at 4:3, and the port reproduces that squeeze on purpose so the images line up.
- lmblender's Standard view transform renders dark tones darker than Blender (for example 38 instead of 56 out of 255 for a linear value of 0.04), which accounts for most of the difference on dark backgrounds.

## Run both

From the repository root (the Blender command needs Blender 5.x on your PATH):

```sh
mkdir -p build
lmscript examples/render-mesh-xml-oracle.lms
blender -b --factory-startup --python docs/tutorial/blender/py/render-mesh-xml-oracle.py
```

lmblender writes into `build/`; the Blender port writes the same file names into `blender/`.

## Blender port

The port calls [lmb_bpy.py](py/lmb_bpy.py), which implements each lmblender call with bpy and the host's semantics.

<!-- code: blender/py/render-mesh-xml-oracle.py -->
```python
# SPDX-FileCopyrightText: 2025-2026 lmblender contributors
# SPDX-License-Identifier: MIT
# Blender/bpy port of examples/render-mesh-xml-oracle.lms (generated by docs/tutorial/blender/lms2py.py, reviewed by hand)
import os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import lmb_bpy

scene = lmb_bpy.Scene()
mesh = scene.import_obj("tests/fixtures/tetra.obj")
scene.render_png("blender/imported-mesh-xml.png", 32, 256, 192)
lmb_bpy.done()
```
