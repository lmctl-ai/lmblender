# material-principled in lmblender and Blender

Goal: render [examples/material-principled.lms](../../../examples/material-principled.lms) with lmblender and the same scene with Blender 5.2 from Python, and compare the results.

Left: lmblender. Right: Blender.

![material-principled.png: lmblender left, Blender right](images/material-principled--material-principled.jpg)

`material-principled.png`: mean absolute difference 10.4 of 255, silhouette overlap 1.00.

## Timing

| Renderer | Seconds, whole run | Binary |
|---|---|---|
| lmblender | 0.9 | v0.3.4 release |
| Blender 5.2.2 | 1.2 | source build, Cycles CPU, about 0.8 s of it is Blender startup |

Both runs used four threads on a four-core Neoverse-N1 (AWS Graviton2) Linux arm64 host.

## Differences and gaps

- The scene sets no camera. lmblender's fallback view is squeezed about 1.5 times horizontally at 4:3, and the port reproduces that squeeze on purpose so the images line up.
- lmblender's Standard view transform renders dark tones darker than Blender (for example 38 instead of 56 out of 255 for a linear value of 0.04), which accounts for most of the difference on dark backgrounds.

## Run both

From the repository root (the Blender command needs Blender 5.x on your PATH):

```sh
mkdir -p build
lmscript examples/material-principled.lms
blender -b --factory-startup --python docs/tutorial/blender/py/material-principled.py
```

lmblender writes into `build/`; the Blender port writes the same file names into `blender/`. The lmblender example prints nothing when it succeeds, so check that the image exists; it also leaves its compiled `.dslb` file in `build/`.

## Blender port

The port calls [lmb_bpy.py](py/lmb_bpy.py), which implements each lmblender call with bpy and the host's semantics.

<!-- code: blender/py/material-principled.py -->
```python
# SPDX-FileCopyrightText: 2025-2026 lmblender contributors
# SPDX-License-Identifier: MIT
# Blender/bpy port of examples/material-principled.lms (generated by docs/tutorial/blender/lms2py.py, reviewed by hand)
import os, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import lmb_bpy

scene = lmb_bpy.Scene()
mesh = scene.import_obj("tests/fixtures/tetra.obj")
scene.world_color(0.08, 0.42, 0.12, 0.5)
scene.point_light(-4.0, -3.0, 7.0, 1.0, 0.82, 0.62, 550.0)
blue = scene.material(0.08, 0.18, 0.85, 0.1, 0.32, 0.0, 0.08, 0.18, 0.85, 2.0)
mesh.set_material(blue)
scene.render_png("blender/material-principled.png", 32, 256, 192)
lmb_bpy.done()
```
