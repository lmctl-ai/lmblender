# Roadmap

| Area | Status | Evidence / remaining work |
|---|---|---|
| lmscript DSL v5 host and embedded schema | Usable | `scene.version()` and rendering examples; `./test.sh` checks schema embedding and the static ELF. |
| Static CPU Cycles executable | Usable | `scripts/configure-cycles-static.sh`; XML oracle, direct renderer, and `ldd: not a dynamic executable` gates pass. |
| OBJ/STL import and direct Cycles rendering | Usable | OBJ and ASCII/binary STL mesh imports; direct C++ nodes build meshes, objects, shaders, camera, lights, and world. |
| Materials and image textures | Partial | Principled, checker, noise, and bounded PNG/JPEG/EXR path binding; PNG checker fixture verifies face UVs. JPEG/EXR inputs, packed assets, and explicit color space controls are unverified. |
| Camera and transforms | Partial | Perspective/look-at and orthographic projection; fitted framing, translations, scales, and instance API. Panoramic optics/DOF are absent. |
| Image output | Partial | PNG supports embedded Blender 5.2 Standard/Filmic/AgX display LUTs; EXR remains scene-linear. Blender golden renders pass at RGB RMSE 0.80/255 (Standard), 0.73/255 (Filmic), and 0.80/255 (AgX). `render_passes` writes Combined, Z, Normal, and albedo EXR plus normalized PNG; ramp test has monotonic depth 1.000 and 92.1% unit-normal coverage. |
| CPU denoising | Static dependency verified; Cycles integration pending | `scripts/build-oidn-static.sh` builds CPU OIDN 2.5 archives and links/runs its RT filter in a 53,634,528-byte fully static smoke executable. Current Cycles build still has `WITH_OPENIMAGEDENOISE=OFF`; renderer denoising is not yet exposed. Static glibc warns OIDN's unused module-loader path calls `dlopen`. |
| Instance geometry sharing | Pending | Current renderer builds one Cycles mesh node per object. Reusing a `Geometry *` through `Object::set_geometry` (even after `tag_update`) yielded a blank frame; independent geometry nodes yield the expected two silhouettes. Blender's integration additionally keys geometry by datablock and tracks synchronization in `intern/cycles/blender/geometry.cpp` (`GeometryKey`, `geometry_map`, `geometry_synced`) before attaching it in `object.cpp::sync_object`. The direct host bypasses that BlenderSync lifecycle; a correct direct-node ownership/update path remains to be established. |
| lmcad composition gallery | Partial | Mug, plate-with-holes, and U-channel bracket compose examples have numeric QA in `docs/MILESTONE3-QA.md`; eight-angle mug/bracket still-image turntables pass strict framing and adjacent-view checks in `docs/TURNTABLE-QA.md`. Turntables are separate stills, not encoded video. |
| Static XML oracle | Test-only | Retained to compare output against direct Cycles construction; production rendering uses the C++ node API. |
