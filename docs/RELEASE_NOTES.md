## lmblender 0.2.0 — Linux arm64

Static CPU Cycles host with direct C++ scene construction, OIDN denoising, mesh import, procedural materials, EXR passes, display transforms, keyed transform/camera/material-color sequences, and APNG output. The archive contains the DSL v5 schema, LLM API guide, animation guide, third-party notices, and license texts.

Verified on aarch64 Linux: `ldd` reports `not a dynamic executable`; `test.sh` passes the complete render, import, schema-signature, image-quality, and Blender comparison suite. This is a draft release for review.
