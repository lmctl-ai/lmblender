# Contribution and provenance rules

Project-authored host code is MIT-licensed where marked with `SPDX-License-Identifier: MIT`. Blender-derived files and data are kept separate and marked with their applicable GPL license. The combined executable is GPL-3.0-or-later; see [LICENSE_AUDIT.md](LICENSE_AUDIT.md).

Do not submit third-party source, generated tables, fonts, patches, or binary assets without a written provenance note naming the upstream source, exact version or commit, and license. Include the applicable license text in `licenses/` and update `THIRD_PARTY_NOTICES.md` and the audit before merging. Generated code must also identify its generator and the license terms that apply to the generated output.
