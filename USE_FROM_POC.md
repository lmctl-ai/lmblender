# Use lmblender from the homepage-video POC

The stable host install is refreshed with `scripts/release.sh`:

- Binary: `/home/ubuntu/lmblender-release/bin/lmblender`
- Schema: `/home/ubuntu/lmblender-release/schema/lmblender.dsl.json`
- Guide/examples: `/home/ubuntu/lmblender-release/docs/LLM_GUIDE.md` and `examples/`

Compile `.lms` with `lmscript` and the installed schema, then invoke the standalone binary on the generated bytecode. It does not start Blender or run Python scripts.

```lmscript
out = ARGV.len() > 0 ? ARGV[0] : "build/diagram.dslb";
p = _dsl_ schema="/home/ubuntu/lmblender-release/schema/lmblender.dsl.json";
scene.use_preset("diagram-dark-16x9-final");
scene.set_threads(4);
let lead = scene.glow_orb(0.0, 0.0, 0.0, 0.65, 1.0, 0.62, 0.12, 2.5);
scene.render_png("build/diagram.png", 0, 1280, 720);
end _dsl_
savedsl(p, out);
```

Run it with:

```sh
PATH="/home/ubuntu/lmblender-release/bin:$PATH" lmscript diagram.lms build/diagram.dslb
/home/ubuntu/lmblender-release/bin/lmblender --dsl build/diagram.dslb
```

The diagram draft preset targets 960x540, 8 spp, no denoising (measured about 0.41 s/frame on this host). Diagram final targets 1280x720, 16 spp, fast CPU OIDN (about 2.00 s/frame for a simple emissive scene). These are benchmark observations, not render-time guarantees; complex glossy, volume, or textured scenes take longer. The fast denoiser was measured at 47.14 dB PSNR and 0.99451 windowed SSIM against a 256-spp high-quality reference for a glossy sphere/floor scene. A controlled 960x540 Cycles rerun measured OIDN at 0.91 s with NEON and four TBB threads; see [docs/OIDN_AUDIT.md](docs/OIDN_AUDIT.md). Higher no-denoise sampling was slower and missed the same-scene 0.95 SSIM gate. See [docs/THROUGHPUT.md](docs/THROUGHPUT.md) for profiles and quality limits.
