# The 3D host family

lmblender, lmcad, lmmagnum and lmfilament are four static lmscript `_dsl_` hosts for 3D scenes that share many examples. This repo is **lmblender**: Blender Cycles (CPU, Embree, OIDN) path tracing; Z-up; `camera_look_at(..., fov)` vertical; degrees.

The cross-repo reference (host comparison, DSL cheat sheet, porting rules, shared-example matrix, README gallery rules, how CI versions releases,
per-repo test commands) lives in lmcad: https://github.com/lmctl-ai/lmcad/blob/main/durable-memory/20-sibling-3d-hosts.md
(locally `../lmcad/durable-memory/20-sibling-3d-hosts.md`). Read it before porting an example between repos.
